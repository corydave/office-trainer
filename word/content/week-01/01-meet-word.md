Word looks crowded at first, but it has only a few parts:

| Part | Where | What it does |
|---|---|---|
| **Ribbon** | Across the top | Commands grouped into tabs (Home, Insert, Layout and so on). Each tab is split into groups, such as Font and Paragraph |
| **Backstage view** | Select **File** | Everything about the file itself: Save, Save As, Print, Export, Info |
| **Quick Access Toolbar** | Above or below the Ribbon | Your own shortcut buttons. Desktop Word lets you add any command |
| **Search box** | Top of the window | Type what you want to do ("margins", "symbol") and Word finds the command. On Windows, [[key: Alt+Q]] jumps to it |
| **Status bar** | Bottom edge | Page and word count, proofing status, view buttons and zoom |

::: callout tip
When you can't find a command, use the search box. It finds commands, not just text, and it works the same way in Word for the web and desktop Word.
:::

## Views

Word can show the same document in different ways. Changing the view never changes the file.

- **Print Layout** shows pages as they will print. You will work here most of the time.
- **Read Mode** (desktop) or **Reading view** (web) hides the Ribbon so you can read comfortably.
- **Web Layout** (desktop) shows the document as one long page with no page breaks, the way it would look as a web page. You will use it again in Week 4, when you save a resume as a web page.

Switch views on the **View** tab, or with the small buttons on the right side of the status bar.

## Files, names and places

A file has three things you control: its **name**, its **location** and its **format**.

- **Name it on purpose.** Use a pattern your instructor (or your future self) can sort: `Lastname_W1_Letter.docx`. Avoid names like `Document1` or `final final 2`.
- **Choose the location.** Saving to **OneDrive** keeps the file online, turns on **AutoSave** and lets you open it from any computer. Saving to the computer (**This PC** or **Mac**) keeps it on that machine only.
- **Know the format.** The three-to-four letters after the dot (the **extension**) tell you what kind of file it is.

| Extension | What it is | Opens in Word? |
|---|---|---|
| `.docx` | A Word document (the normal format) | Yes |
| `.doc` | An older Word document (Word 97-2003) | Yes, in Compatibility Mode |
| `.dotx` | A Word template | Yes, as a new document based on it |
| `.pdf` | A fixed-layout document for sharing and printing | Desktop Word converts it for editing; layout may shift |
| `.rtf` / `.txt` | Rich text / plain text | Yes |
| `.odt` | OpenDocument text (LibreOffice and others) | Yes |
| `.xlsx` / `.pptx` | Excel / PowerPoint | No - use those apps |
