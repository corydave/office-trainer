::: callout why
You'll write papers in almost every course you take. Set up the format once, in a template, and every new paper starts correct: margins, fonts, spacing, header and page numbers, all done.
:::

## What you'll make

1. **A paper template** (.dotx) in **APA 7th** or **MLA 9th** edition style: modified Normal and heading styles, the header and page numbers, and a title page (APA) or heading block (MLA).
2. **A 3 to 5 page paper** made from that template, with headings, at least one list, a footnote or endnote, at least **three real sources** cited with the citation manager, and a generated reference list.

You may reuse a paper from another course this semester. That's encouraged: it ties this skill to your real work.

Name the files `Lastname_P2_Template.dotx` and `Lastname_P2_Paper.docx`.

## Set up the template

| Setting | APA 7th (student paper) | MLA 9th |
|---|---|---|
| Margins | 1 in all around | 1 in all around |
| Normal style | 12 pt Times New Roman, 11 pt Calibri or 11 pt Arial, double spaced, 0 pt before and after, 0.5 in first-line indent | 12 pt Times New Roman, double spaced, 0.5 in first-line indent |
| Header | Page number at top right on every page | Last name and page number at top right |
| First page | Title page: title, your name, affiliation (department and college), course, instructor, due date | Heading block: your name, instructor, course, date, then the title |
| Headings | Heading 1: centered, bold. Heading 2: left, bold | Not required; if used, keep them consistent |
| References | "References" on a new page | "Works Cited" on a new page |

To save a template: [[path: File > Save As]], choose **Word Template (.dotx)** as the file type. Open it later with **File > New > Personal** (desktop Word), or double-click the .dotx: Word opens a new, untitled document based on it.

::: callout ai
Optional: ask an AI tool to explain one APA or MLA rule you're unsure about. Then check the answer against the style guide itself (the library has both). If an AI tool suggests a source, find it in the library database before it goes into the citation manager. Invented sources are a common AI mistake.
:::

::: platform web
The citation manager and saving as .dotx need desktop Word. Campus labs have it, and your FLCC Microsoft 365 account includes it.
:::

## Check before you submit

Run these checks on your **paper**. They don't grade anything; they catch the problems that cost the most points.

::: preflight P2-check
title: Preflight for your paper
starter: none
platform: web

- step: Margins are 1 in all around.
  check: page.is margins=1in
- step: The header has an automatic page number.
  check: field.present code="PAGE" in=header
- step: Headings use heading styles, with no skipped levels.
  check: access.is rules="headings"
- step: At least three sources are cited, and there's a generated reference list.
  check: citation.is citations=3 bibliography=true
  platform: desktop
- step: No empty paragraphs used as spacing (never two in a row).
  check: para.noEmpty max=1
:::

## How it's graded

::: rubric P2
- P2-a | 20 | CLO2 | Headings use real heading styles, and the Navigation pane shows the outline.
- P2-b | 20 | CLO1 | The layout follows the style guide: margins, spacing, header, page numbers and the title page or heading block.
- P2-c | 25 | CLO2 | Citations and the reference list are generated by Word, and every source is real and checked.
- P2-d | 15 | CLO2 | Lists, breaks and notes are used correctly.
- P2-e | 20 | CLO2 | The .dotx template opens a new, correctly formatted document.
:::
